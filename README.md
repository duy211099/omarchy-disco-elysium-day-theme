# Disco Elysium Day — Omarchy theme

A light theme: an overcast Revachol morning on watercolor paper. Soft ink (~9:1) on aged cream `#e8e0cc`, rust accent `#a9512a`.

![preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/duy211099/omarchy-disco-elysium-day-theme
```

Companion theme: [Disco Elysium Night](https://github.com/duy211099/omarchy-disco-elysium-night-theme)

## Palette

Terminal colors follow the game's four skill groups:

| Skill group | Color |
|---|---|
| Intellect | blue |
| Psyche | magenta |
| Physique | red |
| Motorics | ochre yellow |

Every text color is at least 4.5:1 against both `background` and `dark_background`.

Terminal, editor and app configs are generated by Omarchy from `colors.toml`.

## Wallpapers

Original abstract oil-paint style images generated with ImageMagick. No game artwork is included.
